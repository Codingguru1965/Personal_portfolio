# 🌐 Personal Portfolio

A modern, responsive, and interactive **Personal Portfolio Website** built with **React.js**. This portfolio showcases my skills, projects, technologies, and provides a way to connect with me.

## 🚀 Features

* 📱 Fully Responsive Design
* 🎨 Modern and Clean UI
* ⚡ Interactive User Experience
* ✨ Smooth GSAP Animations
* 🎬 Framer Motion Animations
* 🖱️ Parallax Tilt Effects
* ⌨️ Typewriter Text Animation
* 🔄 Preloader Animation
* 🎉 Canvas Confetti Effects
* 👨‍💻 Skills & Technologies Showcase
* 📂 Projects Showcase
* 📞 Contact Section
* 🧭 Responsive Navigation
* 🌐 Cross-Browser Compatible

## 🛠️ Technologies & Libraries

### Frontend Technologies

* **HTML5** – Semantic structure and webpage content
* **CSS3** – Styling, animations, and responsive layouts
* **JavaScript (ES6+)** – Dynamic functionality and interactions
* **React.js** – Component-based frontend development
* **Bootstrap 5** – Responsive grid system and UI components

### React Libraries

| Library                 | Purpose                              |
| ----------------------- | ------------------------------------ |
| **React Bootstrap**     | Bootstrap components for React       |
| **React Icons**         | Icons throughout the portfolio       |
| **React Router DOM**    | Client-side routing                  |
| **Typewriter Effect**   | Animated typing text                 |
| **React Parallax Tilt** | Interactive 3D tilt/parallax effects |
| **Framer Motion**       | UI animations and transitions        |
| **GSAP**                | Advanced animations                  |
| **@gsap/react**         | GSAP integration with React          |
| **AOS**                 | Scroll-based animations              |
| **Canvas Confetti**     | Confetti celebration effects         |

### Development Tools

* **Vite** – Fast development server and build tool
* **ESLint** – Code quality and linting

## ⚙️ Installation & Setup

### 1. Clone the Repository

```bash
git clone https://github.com/Codingguru1965/Personal_portfolio.git
```

### 2. Navigate to the Project Directory

```bash
cd Personal_portfolio
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Start the Development Server

```bash
npm run dev
```

### 5. Build for Production

```bash
npm run build
```
